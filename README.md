# 🌍 Travel Guru

Travel Guru is a responsive travel website designed to help users explore destinations across India and plan their trips.

## ✨ Features

- 🏛️ Explore popular destinations
- 📍 Destination guides
- 🍴 Food recommendations
- 🏨 Stay options
- 🚕 Ride comparison
- 🔎 Destination search
- 📱 Responsive design
- 🗺️ Travel-related information and links

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Explore the Travel Guru website.
